# 文档目录

将需要问答的保险文档（`.txt` 或 `.pdf`）放入此目录，然后运行：

```bash
python3 indexer.py
```

索引器会扫描此目录下所有 `.txt` / `.pdf` 文件，分块后调用 Jina Embeddings 向量化，并写入 Elasticsearch 的 `knowledge_base` 索引。

## 命名规范

建议采用 `序号-标题.txt` 的命名方式（如 `01-雇主责任险条款.txt`），系统会自动提取标题为「雇主责任险条款」。

## 示例问题

UI 启动后内置的推荐问题示例：
- 工伤保险和雇主险有什么区别？
- 雇主责任险的赔偿范围是什么？
- 商业综合责任保险是什么？
- 比较所有保险产品的保障范围区别
